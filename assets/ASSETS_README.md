# Required Asset Files

Copy the following PNG files from your Excelra brand assets into this folder:

## Brand Assets
- Logo.png - Excelra logo
- Slogan.png - "Where data means more" 
- Wave.png - Brand wave graphic

## Page Icons
- repurpose.png - Main repurposing icon
- repurpose2.png - Page/tab icon
- Start.png - Start/run button icon
- Input.png - Input/configuration icon
- Analysis.png - Analysis icon
- ranking.png - Ranking/results icon
- Home.png - Home/overview icon

## Data Source Icons
- Clinical.png - Clinical trials
- adverse.png - Adverse events
- books.png - Literature
- flow.png - Pathways
- metabolomic.png - Omics data
- Network.png - Interactome
- lipidomimc.png - Lipidomic profiling (note: filename has extra 'm')

## Chart/Visualisation Icons
- heatmap.png - Heatmap visualisation
- deep_dive.png - Deep-dive analysis
- Bar_chart.png - Bar chart
- Pie_chart.png - Pie chart

## Other Icons
- Data acquisition.png - Data acquisition
- Novel.png - Novel/new indication
- Gene.png - Gene/genetic data
- total.png - Total count metric
- tier1.png - Tier I indicator
- tier2.png - Tier II indicator

## Note
All icons should be PNG format with transparent backgrounds where appropriate.
The application will show fallback text if any icons are missing.
